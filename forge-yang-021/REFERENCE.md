## 学理根（为什么这套语言成立）

- **概念隐喻**（Lakoff & Johnson《我们赖以生存的隐喻》1980）：空间隐喻（点线面环）是人类最根基的认知组织方式——用几何语言描述 prompt 结构，人和模型都零学习成本。
- **认知负荷**（Sweller 认知负荷理论）：一次只决策一个维度，负荷最低——所以逐维快问，不一次抛全部选项。
- **上下文工程**（Anthropic《Effective context engineering for AI agents》2025，https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents）：上下文是有限资源，有注意力预算与 context rot——所以路径要「最小高信号 token 集」。
- **模式目录**（White et al.《A Prompt Pattern Catalog》arXiv:2302.11382）：组织形式可以编目成可检索的模式——本文件的模式卡即此法。

## 几何四形（管排布）

| 形 | 隐喻 | 什么时候用 | 工程要点 |
|---|---|---|---|
| 点 | 直接表达，展开可能性空间 | 发散、探索、开局——要可能性不要收敛 | 一句直给，不加约束；显式说「给多种可能」 |
| 线 | 两点定一线 | 要方向锚定 | 成对提供：正例+反例（对比定轴）、目标+阻碍（张力定轴）。线是面的特例 |
| 面 | 线+约束围合 | 边界明确、要收敛 | 平行约束（同类规则族）或相交约束（交叉定位）；三角=三组约束、四边=四组，每组约束一条边 |
| 环 | 卷曲成环，输出回流输入 | 迭代改进、多轮任务（最高级形态） | 横向：上一轮 output A 作为/影响下一轮 input B；纵向：过滤压缩提供上下文（保高信号、清工具残渣）。循环三要素必写：循环不变量 / 退出条件 / 层间传递 |

升维链：点（零约束开空间）→ 线（一对参照定方向）→ 面（多约束围边界）→ 环（闭环自迭代）。高维包含低维：线是面的特例，面可卷成环。

## 调用模型五料（管内容；开放分类，包含但不限于）

| 料 | 给模型什么 | 供给方式 |
|---|---|---|
| 架构设计 | 系统的结构决策与理由——模型知道「为什么这样搭」 | 正文内嵌要点 + 路径指向设计文档 |
| 思维模型 | 看问题的框架（认知图式）：premortem、二八、第一性原理… | 正文内嵌；一个 prompt 最多一两个 |
| 流程知识 | 步骤顺序与先后依赖——先做什么后做什么 | 正文内嵌编号步骤 |
| 验收节点 | 怎么算对、错了怎么定位、怎么靶向纠正 | 正文内嵌：验收标准 + 纠错路径 |
| 黄金样例 | 见过好的——审美锚点（multishot） | 正文内嵌 1-2 个正例；反例与正例成对即成「线」 |

## 摸项目规程（第 2 步细则）

1. 分层 `Glob` 摸目录结构（先两层，别递归全开）。
2. 按意图关键词 `Grep` 定位高相关文件。
3. `Read` 高相关文件的头部（前 100 行内），不深读全文件。
4. 产出「路径候选清单」：每条 = 路径 + 一句「它能供什么上下文」。
5. 时限自律：摸项目是快动作——几轮工具调用还没眉目就停，路径块声明空缺，不硬凑。

## 上下文路径规程

- 文件路径 = 轻量标识符，运行时动态加载——prompt 里只放路径 + 一句用途，**不搬运文件内容**。
- 每条路径必须答得上「为什么带它」；答不上就删。
- 宁少勿滥：最小高信号 token 集。
- 路径块放成品末尾，独立成块。

## XML 标签法（注意力引导）

- 结构块用标签圈定：`<task>` `<model>`（调用模型块）`<context_paths>` `<output>` 等——标签即注意力路标。
- 用户的中文排版习惯（`===`/`---`、「」）用在对话里；**成品 prompt 内以标签为主**，避免两套符号打架。

## 模式卡（形×料 组合骨架；组装时取卡填充）

### 卡1 · 点+样例 —— 发散开局

意图：要可能性，不要收敛。

```text
<task>{一句话任务}</task>
<style>给 {N} 种不同思路，每种一段；不评判优劣</style>
<golden_example>{见过好的样子，一段}</golden_example>
```

### 卡2 · 线+对比 —— 两点定方向

意图：方向锚定，防跑偏。

```text
<task>{一句话任务}</task>
<line>
  <positive>{正例：要这个样子}</positive>
  <negative>{反例：不要这个样子}</negative>
</line>
```

### 卡3 · 线+目标阻碍 —— 张力定轴

意图：目标明确、阻碍真实。

```text
<task>目标：{要什么}</task>
<obstacle>阻碍：{卡在哪}</obstacle>
<ask>{绕开阻碍达成目标}</ask>
```

### 卡4 · 面+三角 —— 三约束围合收敛

意图：边界明确、要收敛的执行任务。三边 = 目标线 + 边界线 + 验收线。

```text
<task>{一句话任务}</task>
<goal>{目标与完成定义}</goal>
<constraints>{边界规则，逐条}</constraints>
<acceptance>{验收标准 + 纠错路径}</acceptance>
<context_paths>
- {路径} —— {供什么上下文}
</context_paths>
```

### 卡5 · 面+全料四边 —— 重任务围合

意图：复杂执行任务。四边 = 流程 + 架构 + 验收 + 样例。

```text
<task>{一句话任务}</task>
<process>{编号步骤与依赖}</process>
<architecture>{结构决策与理由，或指向路径}</architecture>
<acceptance>{验收节点：怎么算对 / 怎么定位错 / 怎么靶向纠}</acceptance>
<golden_example>{正例一段}</golden_example>
<context_paths>
- {路径} —— {供什么上下文}
</context_paths>
```

### 卡6 · 环+迭代 —— 输出回流（最高级形态）

意图：多轮迭代改进，自我精化。

```text
<task>{一句话任务}</task>
<loop>
每轮：
  输入 = 上一轮输出 {A}（或其压缩摘要）
  执行 {流程步骤}
  保持：{循环不变量——每轮必须守住什么}
  自检：{验收节点}——不过则按 {定位方式} 靶向修正
  若 {退出条件} 满足：停止
层间传递：{内层产出怎么传给外层}
</loop>
<compaction>长对话时：保 {高信号要素清单}，清工具残渣与冗余</compaction>
<context_paths>
- {路径} —— {供什么上下文}
</context_paths>
```
